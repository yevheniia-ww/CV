## Опис завдання

Цей проєкт створено як домашнє завдання з теми HTML та налаштування текстового редактора. Мета роботи — використати отримані знання та створити HTML-сторінку з власним резюме.

## Обов’язкові вимоги

- створити HTML-сторінку зі своїм резюме;
- додати особисте фото;
- додати посилання на соціальні мережі;
- написати код без синтаксичних помилок.

## Екстра-завдання

- створити другий HTML-документ із резюме англійською мовою;
- в англомовному документі використати атрибут `<html lang="en">`;

## Виконання

У проєкті створено сторінку резюме українською та англійською мовами. До сторінки додано фото, посилання на соціальні мережі та базову стилізацію.

Також було налаштовано Visual Studio Code для зручної роботи з HTML/CSS.

## Файли проєкту

- `index.html` — резюме;
- `script.js` — файл для того, щоб змінювати мову;
- `style.css` — файл стилів;
- `photo.jpg` — фото для резюме.

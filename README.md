# Моє резюме

## Опис завдання

У межах домашнього завдання потрібно було використати отримані знання з HTML та створити вебсторінку зі своїм резюме.

Також потрібно було налаштувати текстовий редактор під себе, переглянути його основні функції, дослідити корисні можливості та встановити плагіни для зручнішої роботи.

## Виконані вимоги

- створено HTML-сторінку з резюме;
- додано особисте фото;
- додано посилання на соціальні мережі;
- код написано без синтаксичних помилок;
- створено другий HTML-документ із резюме англійською мовою;
- в англомовному документі використано `<html lang="en">`;
- налаштовано Visual Studio Code;
- встановлено корисні плагіни для роботи з HTML/CSS.

## Файли проєкту

- `index.html` — резюме українською мовою;
- `resume-en.html` — резюме англійською мовою;
- `style.css` — файл стилів;
- `photo.jpg` — фото для резюме.
